**앞으로 신규 레시피 업데이트 루틴:**

1. **블로그 포스팅** 완료
2. **화보집 이미지** 작업 완료 (구글 플로우로 0.jpg/1.jpg/2.jpg 제작)
3. **저한테 업데이트 요청** → 제가 에이전트용 프롬프트 만들어드림
4. **에이전트에게 전달** → 작업 완료 후 git push
5. **Render 자동 배포** → 사이트 자동 반영 ✅

---

**제가 만들어드릴 프롬프트에는:**
- 블로그 URL에서 재료/베이킹순서 추출
- PROJECTS, INGREDIENT_DICT, RECIPE_STEPS_DB 추가
- 카테고리 분류
- 화보집 폴더 확인
- 커밍순 카드 업데이트
- node -c 검증
- git add -A && git commit && git push

이 모든 게 포함될 거예요.

업데이트 준비되시면 블로그 URL이랑 디저트 이름만 알려주시면 바로 프롬프트 만들어드릴게요! 😊
