# 프로젝트 두부 - 버전 1.1 (v1.1)

순두부 디저트 레시피 아카이브 플랫폼 '프로젝트 두부'의 v1.1 정적 릴리즈 아카이브입니다.

## 아카이브 정보
- **버전:** 1.1
- **저장일자:** 2026년 6월 22일
- **완성 레시피 수:** 38개 (Vol.1~38)
- **커밍순:** Vol.39 순두부 자색고구마 롤치즈스콘

## 이전 버전 (v1.0) 대비 변경사항 (모바일 반응형 최적화)
1. **모바일(768px 이하) 전용 반응형 디자인 전면 적용**
2. **메인 아코디언 UI 최적화**: 모바일 환경에서 아코디언 인터랙션을 제거하고 최신 5개 카드 + 커밍순 리스트 형식으로 전환하여 스크롤 및 터치 사용성 개선
3. **시즌 이벤트 모달 개선**: 모바일 전용 1열 가로 슬라이드 캐러셀 방식 도입, 좌우 터치 보조 화살표 및 하단 도트 인디케이터 구성, 반투명 원형 닫기(×) 버튼 고정 및 닫을 시 홈 목록 복귀 로직 연동
4. **책장(실패없는 베이킹노트) 레이아웃 최적화**: 모바일에서는 가로 터치 스냅 스크롤을 활용한 풀스크린 매거진 스프레드 방식으로 자동 변환, 데스크탑 뷰는 기존의 페이지네이션 기반 3D 책장 방식 유지
5. **상세 레시피 모달 반응형 개편**: 모바일 환경에서 반투명 닫기 버튼 고정, 헤더 이미지 영역 확대, 가로 책갈피 탭 재배치, 스크롤 최적화 및 컴팩트한 재료/순서 정보 뷰 제공
6. **디저트 화보북 상세보기 개선**: 모바일 환경에서 좌우 스와이프 슬라이더 대신 3장의 고화질 화보 이미지를 6px 간격(검은색 배경)으로 세로 스크롤하여 풀 너비로 감상할 수 있는 세로 갤러리 뷰로 전환, 최상단에 반투명 닫기(×) 버튼 고정
