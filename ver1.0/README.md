# 프로젝트 두부 - 버전 1.0 (v1.0)

순두부 디저트 레시피 아카이브 플랫폼 '프로젝트 두부'의 v1.0 정적 릴리즈 아카이브입니다.

## 아카이브 정보
- **버전:** 1.0
- **저장일자:** 2026년 6월 19일
- **완성 레시피 수:** 38개 (Vol.1~38)
- **커밍순:** Vol.39 순두부 자색고구마 롤치즈스콘
- **화보집:** 38개 전체 보유 (각 폴더 내 `화보집/0.jpg`, `1.jpg`, `2.jpg` 완비)

## 주요 기능
1. **메인 아코디언 (Sensory Accordion Artbook):** 최신 디저트 5종 및 커밍순 카드를 수려한 아코디언 UI로 노출
2. **실패없는 베이킹노트 (3D Bookcase):** 전체 38권의 레시피북을 오름차순으로 책장에 정렬하여 가상 서가 구현
3. **시즌 이벤트 (Annual Tradition):** 발렌타인, 설날-추석, 할로윈, 크리스마스 등 시기별 특별 테마 및 레시피 연동
4. **디저트 화보북 (Exhibition Gallery):** 각 레시피의 고화질 베이킹 화보 3종 슬라이더 뷰어 연동
