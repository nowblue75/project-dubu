# 프로젝트 두부 - 버전 1.2 (v1.2)

순두부 디저트 레시피 아카이브 플랫폼 '프로젝트 두부'의 v1.2 정적 릴리즈 아카이브입니다.

## 아카이브 정보
- **버전:** 1.2
- **저장일자:** 2026년 6월 22일
- **v1.1 대비 변경사항:** 사이트 기능 변경 없음, GitHub 저장소 용량 최적화 작업

## 주요 최적화 내용
1. **추적 제외 설정**: `.gitignore` 파일에 `*.pdf`, `*.pptx`, `*.mp4` 규칙을 추가하여, 웹 플랫폼에서 실제로 로드하여 사용하지 않는 대용량 미참조 설계/소스 파일들이 앞으로 Git 추적을 받지 않도록 구성했습니다.
2. **역사적 Git 히스토리 완전 소거**: `git-filter-repo` 도구를 사용하여 과거 커밋 히스토리 전체에 물려 있던 모든 PDF/PPTX/MP4 개체 노드 데이터를 완전히 영구적으로 필터링 삭제했습니다.
3. **저장소 경량화 (.git 압축)**: 
   - 최적화 작업 결과 `.git` 폴더 용량이 **2.38 GB → 1.94 GB**로 감소하여 **약 416 MB의 용량을 획기적으로 절감**했습니다.
   - 남은 1.80 GiB 용량은 플랫폼이 실시간 로드하는 순수 고해상도 디저트 이미지 리소스(약 1057개, 총 1.75 GB)의 실제 물리 용량으로, 가장 이상적인 최소 규모에 도달했습니다.
4. **클라우드 배포 최적화**: Render 등 외부 정적 웹 호스팅 서비스로 배포할 시 빌드 속도 및 트래픽 요건을 원활하게 소화하기 위한 사전 준비 작업을 마쳤습니다.
