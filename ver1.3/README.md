# 프로젝트 두부 - 버전 1.3 (v1.3)

순두부 디저트 레시피 아카이브 플랫폼 '프로젝트 두부'의 v1.3 정적 릴리즈 아카이브입니다.

## 아카이브 정보
- **버전:** 1.3
- **저장일자:** 2026년 6월 23일
- **변경사항:** 레시피 소장하기 팝업 z-index 수정

## 주요 변경 및 조치 내용
1. **다운로드 팝업 레이아웃 오류 수정**: 상세 모달 화면 내에서 "레시피 소장하기" 버튼 클릭 시 나타나는 재료 및 가이드 팝업 카드(#recipe-card-modal)가 상세 모달 오버레이(.atelier-focus-overlay)의 z-index(30000) 뒤로 숨겨지는 문제를 해결하기 위해, 팝업 카드의 z-index를 **40000**으로 상향 조정했습니다.
2. **화면 중앙 고정**: 모바일 및 데스크탑 뷰 모두에서 팝업이 상세 모달 위쪽 정중앙에 fixed 레이아웃으로 선명히 노출되어 안정적으로 동작하는 것을 최종 확인했습니다.
3. **Render 실서비스 즉시 배포**: 변경 사항을 원격 GitHub 저장소에 병합 후, Render 호스팅 서버(https://project-dubu.onrender.com)에 자동 빌드 배포되어 프로덕션 환경에서도 오류 없이 구동됨을 실증 캡처하여 검증했습니다.
