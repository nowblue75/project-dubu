# 프로젝트 두부 - 버전 1.4 (v1.4)

순두부 디저트 레시피 아카이브 플랫폼 '프로젝트 두부'의 v1.4 정적 릴리즈 아카이브입니다.

## 아카이브 정보
- **버전:** 1.4
- **저장일자:** 2026년 6월 23일
- **변경사항:** Render 서버 의존성 제거, GitHub Pages 정적 배포 전환 (콜드 스타트 방지)

## 주요 변경 및 조치 내용
1. **정적 데이터베이스 추가 (`dubu_data.js`)**: PROJECTS 배열(Vol.1~38)을 토대로 각 디저트 폴더와 이미지 경로를 명시하는 `PHOTOBOOKS` 정적 객체를 추가했습니다.
2. **API 호출 국소화 (`dubu_app.js`)**: `/api/photobooks` 및 `/api/scan_images` 동적 API fetch 호출을 제거하고, `dubu_data.js` 내의 `PHOTOBOOKS` 로컬 정적 상수를 참조하여 런타임에 직접 그리드를 빌드하도록 변경했습니다.
3. **Node.js 서버 단순화 (`server.js`)**: API 엔드포인트 및 디버그 라우트를 소거하고 기본 정적 서빙 및 SPA 룰만 남겼습니다. 이에 따라 Node.js 인스턴스(백엔드) 없이도 저장소의 프론트엔드 에셋 단독으로 GitHub Pages에서 완벽하게 기동하는 순수 정적 사이트가 되었습니다.
4. **GitHub Pages 전환 지원**: 별도의 서버 구동 없이 `index.html` 단독으로 클라우드 기동하여 Cold Start 현상이 완전히 소멸했습니다.
