## 스승 캐릭터명 수정 필요

보고서와 코드에 스승 캐릭터가 **"바루다"**로 되어 있는데, 이건 저희가 캐릭터성 참고용으로 언급했던 웹툰 「AI닥터」에 실제로 등장하는 캐릭터 이름입니다. 저희는 그 캐릭터의 **컨셉**(항상 곁에서 반응하고, 잔소리/유머로 성장을 이끄는 관계형 캐릭터)만 참고하기로 한 것이지, 이름을 그대로 쓰기로 정한 적은 없습니다. 상업 게임에 타 작품의 고유 캐릭터명을 그대로 쓰면 안 되니, 지금 단계에서 바로잡아야 합니다.

**스승의 이름을 "온(溫)"으로 확정합니다.** 아래 항목을 전부 찾아서 수정해주세요:
- 대화 스크립트 내 캐릭터명 (App.tsx 등)
- 컴포넌트/변수명에 "바루다" 또는 유사 표기가 남아있다면 (RecipeBook.tsx 등)
- 세이브 데이터 구조에 캐릭터명이 하드코딩되어 있다면 해당 부분
- walkthrough.md, task.md 등 문서 내 언급

수정 후 `npm run test`와 `npm run dev`로 이름이 전부 "온"으로 정상 표시되는지 재확인 부탁드립니다. 확인되면 다음 챕터 논의로 넘어가겠습니다.
